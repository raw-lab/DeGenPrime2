DeGenPrime on Windows
=====================

1. Install Rust from https://rustup.rs. The default options are fine; accept
   the Visual Studio C++ Build Tools when the installer offers them.
2. Rename install.bat.txt to install.bat. It is shipped with a .txt ending
   because e-mail filters block zip files that contain .bat files.
3. Double-click install.bat. It builds DeGenPrime, copies degenprime.exe to
   %LOCALAPPDATA%\DeGenPrime, adds it to your PATH and creates Start Menu and
   desktop shortcuts called "DeGenPrime" with the DeGenPrime robot icon.
4. Open DeGenPrime from the Start menu. A console window starts the app and
   your browser opens it; close the console window to stop it.

Unaligned sequences are aligned by the built-in MAFFT: there is nothing else
to install.

Command line:  degenprime --help     Self-check:  degenprime doctor
